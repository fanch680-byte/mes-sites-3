🖼️ vs 📥 — Quelle différence ?

🖼️ Favicons

Pour la catégorie active

  • Télécharge les icônes uniquement pour les sites affichés.
  • Affichage immédiat (1–3 s).
  • Pas sauvegardé : après redémarrage, retour aux emojis.
💡 Idéal pour tester ou rafraîchir vite.
📥 Favicons

Pour toutes les catégories

  • Télécharge tous les favicons (tous les sites).
  • Sauvegarde dans ./favicons/domaine.png.
  • Persistant : chargement instantané à chaque lancement.
  • Fonctionne hors ligne.
✅ À faire une fois, au début.

Barre d’outils — Fonctions

  • 🔄 Actualiser : recharge la catégorie.
  • 🖼️ Favicons : icônes rapides pour la catégorie courante.
  • 📥 Favicons : sauvegarde globale et définitive.
  • ➕ Site : ajoute un nouveau site.
  • 📁 Nouvelle catégorie : en haut à droite.
  • ❓ Aide : ouvre ce fichier.

Dossier favicons/

Créé automatiquement après utilisation de 📥 Favicons :

favicons/ ├── youtube.com.png ├── github.com.png ├── google.com.png └── ...

→ Ces fichiers sont utilisés automatiquement au démarrage.

💡 Astuce : Vous pouvez remplacer un favicon manuellement (ex: logo personnalisé).

Conseils d’usage

  1. Au premier lancement : cliquez sur 📥 Favicons.
  2. Ensuite, les icônes s’affichent instantanément.
  3. Utilisez 🖼️ Favicons uniquement si un favicon a changé.

✅ Application conçue pour les écrans haute résolution — compatible Windows 10/11.
